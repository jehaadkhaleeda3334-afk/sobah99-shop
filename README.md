# متجر ٩٩ للسبح

متجر كامل لبيع السبح: واجهة للعميل + لوحة إشراف + قاعدة بيانات.
بدون أي مكتبات خارجية، يحتاج فقط Node.js إصدار 22.13 أو أحدث.

## تشغيل تجريبي على جهازك

```
ADMIN_EMAIL=بريدك@gmail.com ADMIN_PASSWORD=كلمة_مرور_قوية node server.js
```
افتح http://localhost:3000 للمتجر، و http://localhost:3000/admin للوحة الإشراف.

## النشر على الإنترنت (مهم)

المتجر يحفظ الطلبات والصور في مجلد واحد (`DATA_DIR`). لازم تختار استضافة فيها **قرص دائم (Persistent Disk / Volume)** وتربطه بالمجلد `/data`، وإلا تضيع البيانات عند كل إعادة تشغيل. الاستضافات المجانية عادةً ما تدعم هذا.

أي استضافة تشغّل Docker أو Node تنفع (مثل Railway أو Render أو Fly.io أو سيرفر VPS). الخطوات العامة:

1. ارفع محتوى هذا المجلد (أو اربطه بمستودع GitHub).
2. اختر نوع التشغيل: Docker (الملف `Dockerfile` جاهز) أو Node مع أمر التشغيل `node server.js`.
3. أضف قرصًا دائمًا مربوطًا بـ `/data`.
4. أضف متغيرات البيئة التالية:

| المتغير | المعنى |
|---|---|
| `ADMIN_EMAIL` | بريدك الخاص (هو اللي يفتح لك لوحة الإشراف) |
| `ADMIN_PASSWORD` | كلمة مرور قوية للوحة الإشراف |
| `DATA_DIR` | `/data` |
| `SITE_URL` | رابط متجرك مثل `https://99sobah.onrender.com` (لمعاينة الروابط عند المشاركة) |
| `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID` | اختياري: لتصلك رسالة "جاء طلب جديد" على جوالك |

5. اربط دومين (اختياري) من إعدادات الاستضافة. تأكد أن الرابط يبدأ بـ https.

## الدخول للوحة الإشراف

- من الرابط `/admin` بالبريد وكلمة المرور.
- أو من نافذة تسجيل البريد في المتجر: اكتب بريد المدير فيطلب منك كلمة المرور ويدخلك اللوحة.

## أول ما تدخل اللوحة

1. **الإعدادات:** ضع رقم واتساب (مثل 966501234567)، وراجع الآيبان وأسعار الشحن وحد الشحن المجاني. أضف اسم البنك والآيبان ورمز QR للتحويل (اختياري) من نفس الصفحة.
2. **الأقسام:** موجودة (كهرمان، يسر، عقيق، فيروز، كوك)، عدّلها أو أضف.
3. **السبح:** أضف سبحة بالصور والسعر وسعر التكلفة والكمية والمواصفات (كل مواصفة في سطر: `المادة: كهرمان`).
4. **العروض:** أضف صور الستوري اللي تظهر أول المتجر، وتقدر تربط كل صورة بسبحة.

## تنبيه الطلب الجديد

- لوحة الإشراف تفحص الطلبات كل 20 ثانية، وتطلع تنبيه وصوت إذا جاء طلب جديد (والصفحة مفتوحة).
- لتصلك رسالة على الجوال حتى لو اللوحة مقفلة: أنشئ بوت تيليجرام من @BotFather، وضع `TELEGRAM_BOT_TOKEN`، وضع رقم محادثتك في `TELEGRAM_CHAT_ID`، ثم جرّب زر "إرسال تنبيه تجريبي" في الإعدادات.

## الأرباح

الصافي = مبيعات السبح + رسوم الشحن المحصّلة − تكلفة البضاعة − تكلفة الشحن الفعلية − المصاريف ± التعديلات.
تُحتسب فقط الطلبات التي قبلتها (مقبول، مشحون، مستلم). تكلفة الشحن الفعلية تعدلها من تفاصيل كل طلب، وإذا تركتها فارغة تُحسب بقيمة ما دفعه العميل. المصاريف والتعديلات تضيفها من تبويب الأرباح.

## نسخة احتياطية

كل شيء داخل مجلد `DATA_DIR`: ملف `store.db` والصور والإيصالات. انسخه بشكل دوري.

## حفظ البيانات على الاستضافة المجانية
اضبط `BACKUP_GITHUB_TOKEN` (توكن GitHub بصلاحية Contents: Read and write على مستودع النسخ فقط) و`BACKUP_REPO` (مثل `user/sobah99-backup`، مستودع خاص). تُرفع قاعدة البيانات والصور والإيصالات تلقائيًا بعد كل تغيير وتُستعاد عند التشغيل.
